# Stuart Wilson — professional website

## Publish with GitHub Pages

1. Create a public GitHub repository named `YOUR-USERNAME.github.io` (or any repository name for a project site).
2. Upload **both** `index.html` and the entire `assets/` folder, preserving the folder structure.
3. Open repository **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, `main` and `/ (root)`, then save.
4. Your site will be available at `https://YOUR-USERNAME.github.io/` (or `/REPOSITORY-NAME/` for a project site).

## Company icons

All company icon files are stored locally under `assets/` and are served from your GitHub repository. **These are clean initial-based placeholder icons, not official company logos.** This package does not depend on Google's favicon service.

To use official brand icons, obtain permitted SVG or PNG logo assets from each company's brand resources, save them in `assets/` and update the corresponding `src` in `index.html` (or replace the existing SVG files with assets of the same names). Keep the company names and links as they are.
